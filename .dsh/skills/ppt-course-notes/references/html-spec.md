# 页面版式规范（课程学习资料）

生成器 `scripts/build_page.py` 已按本规范渲染；本文件用于修改样式或排查渲染问题时对照。视觉 token 定义在 `assets/style.css`，页面结构由 `build_page.py` 生成。

## 1. 设计 token

| 用途 | 值 |
|---|---|
| 页面底色 `paper` | `#f6f4ee` |
| 卡片底色 `surface` | `#ffffff` |
| 正文 `ink` | `#1f2a24` |
| 次要文字 `muted` | `#6b7a72` |
| 主色 `teal` | `#1f6f5c` |
| 深主色 `teal-dark` | `#155445` |
| 星级/强调 `amber` | `#d97706` |
| 边框 `border` | `#e7e2d8` |
| 危险/错误 | `#c0392b` |

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif`。
- 页面最大宽度 860px，左右留白，内容纵向排列；卡片圆角 14–16px，边框 1px，阴影 `0 10px 36px rgba(31,42,36,.05)`。
- 移动端（≤640px）自动收窄留白，统计栏与底部按钮改为两列/纵向。

## 2. 页面结构（从上到下）

1. **页头**
   - 左上角标签：`PPT / PDF 课程`（青色底、白字）；右上角生成日期。
   - 主标题：章节标题（来自文件名），30px / 900。
   - 概述：一段灰色小字。
   - 统计栏：`章节`、`知识点`、`例题`、`重点` 四等分；数字青色 20px / 900，标签灰色 12px；上下 1px 边框。
   - 合并说明：浅青底小字，如「1 份源文件 → 1 个章节；每份课件独立成章。」
2. **标签栏**：`学习资料` / `导图`，胶囊形、吸顶、当前项白底加阴影。
3. **学习资料**
   - 章节卡片：白色、圆角、边框；左侧方形序号「1」，标题、摘要、来源文件标签，右侧 `−` / `+` 折叠按钮。
   - 展开后：知识点卡片，每个含标题 + 星级（实心 `★` 琥珀色、空心 `☆` `#ded8c8`）、Markdown 正文。
   - 每个知识点下方 `配套练习` 区（浅米色 `#faf8f2`）：练习卡片白色，头部为「例 1」+ 题型标签（青）+ 难度标签（琥珀）+「查看答案」按钮；题干；答案区（`#f7f5ef`，`参考答案` 标签）默认隐藏。
4. **导图**：卡片内工具栏（标题、缩放 − / 百分比 / +、重置、全屏），横向树状图：根节点青色实底白字，一级节点白底青边；有子节点的节点带 −/+ 折叠按钮；点击节点高亮并在底部显示备注。
5. **底部操作**：`复制 Markdown`、`保存学习文档`（下载 `.md`）、`打印 / 存 PDF` 三个胶囊按钮，吸底。
6. **页脚**：一行灰色小字「内容由课件自动整理，仅供复习参考。」

## 3. 交互

- 标签切换不刷新页面；键盘可操作（按钮 + `aria-selected`）。
- 章节默认展开；点击标题切换 `−/+` 与内容显隐。
- 练习答案默认折叠；按钮文字在「查看答案 / 收起答案」间切换，`aria-expanded` 同步。
- 复制 Markdown：优先进剪贴板 API，失败回退 `textarea + execCommand`，并给出短暂提示。
- 保存：用 Blob 下载 `<标题>.md`。
- 打印：隐藏标签栏、底部操作、折叠按钮；自动展开章节与答案；避免卡片跨页断裂。
- 导图缩放：0.6–1.6 倍，按钮调整并显示百分比。

## 4. 数据映射

| 页面元素 | 数据 |
|---|---|
| 标题 | `slides.json.title`（文件名去扩展名）或 `--title` |
| 概述 | 默认「按《文件名》独立整理：1 份课件对应 1 章，包含考点知识点、星级重要度与配套练习。」 |
| 统计 | 章节=1；知识点=合并后数量；例题=全部练习数；重点=星级≥4 的知识点数 |
| 章节摘要 | 脚本生成「本章共 N 个考点：……。」 |
| 来源标签 | 源文件名 |
| 星级 | `importance` 1–5 |
| 练习 | `examples[]`，题型从题干 `**【…】**` 解析 |
| 导图 | 根=章节标题，一级=知识点标题（默认全部，单章最多 40 个；区域可滚动） |

## 5. 自包含要求

- 所有 CSS、JS 内联；不使用 CDN、外部字体、网络图片。
- 不执行课件文本中的任何 HTML/JS（正文全部转义）。
- 页面只依赖浏览器原生能力；复制失败时降级提示用户手动选择文本。
