# 内容规范（课程学习资料）

本规范定义课件如何整理成可直接复习的考点资料，而不是幻灯片文字转写。

## 1. 章节模型

- 一份课件 = 一章；章节标题默认取文件名（不含扩展名），例如 `课程名-第1章.pptx` → `课程名-第1章`。文件名是通用名（`演示文稿`、`课件` 等）时用首页标题，可用 `--title` 覆盖。
- 章节摘要由脚本生成：`本章共 N 个考点：标题1、标题2、……。`
- 同一份课件内不按小节拆章；整份课件共用一个章节卡片。

## 2. 内容取舍（必须过滤）

只保留与考试/复习相关的技术知识：概念、原理、分类、结构、流程、参数、对比、计算方法、易错点。

以下内容不要输出（脚本也会再过滤一次）：

- 课程概况/简介/导入/目标/安排/大纲/考核要求
- 教师、群昵称、群号、联系方式
- 学时、学分、成绩、评分方式
- 参考教材、学习方法/建议、科研入门、论文检索/阅读/写作、就业/面试建议
- 章节导语、纯目录页、致谢页

如果某一块全是这类内容，输出 `{"summary": "", "knowledge_points": []}`，不要硬凑。

## 3. 知识点

- 每块提炼 4–7 个，宁可少而精；整章最多保留 60 个（脚本截断）。
- 标题：简洁名词性短语，如「中断的响应过程」「进程与线程的区别」；不要「本章介绍」「课程概述」这类空标题。
- 正文 `content_md`：150–350 字，用 Markdown 分点，推荐四段结构：
  1. **定义/结论**：一句话说清是什么、解决什么问题。
  2. **关键要点**：`- ` 列表，列 3–5 条必须记住的内容。
  3. **适用条件 / 步骤**：有序列表，写清前提、执行顺序或公式。
  4. **易错点**：`- ` 列表，写常见混淆、边界条件、考试陷阱。
- 重要度 `importance`：1–5 的整数，不要全给 5。建议分布：1–2 个 5 星，2–3 个 4 星，其余 3 星；了解性内容给 2，拓展给 1。

示例：

```markdown
**定义**：中断是 CPU 暂停当前程序、转去执行中断服务程序，完成后再返回原程序的过程。

**关键要点**
- 按来源分为内中断（异常）与外中断（I/O、时钟）
- 响应过程：关中断 → 保存断点 → 识别中断源 → 转入服务程序
- 断点保存的是**下一条指令**的地址

**步骤**
1. 当前指令执行结束后检查中断请求
2. 关中断，保存现场与断点
3. 查中断向量表，转中断服务程序
4. 恢复现场，开中断并返回

**易错点**
- 断点不是当前指令地址
- 中断与子程序调用的区别在于随机性
```

## 4. 配套练习

- 每个知识点 **2 道**，必须有答案；整章至少覆盖 3 种题型。
- 题型 `choice` 选择、`fill` 填空、`true_false` 判断、`calculation` 计算、`short_answer` 简答、`application` 应用。
- `question_md` 开头必须是粗体题型标签：`**【选择题】**`、`**【填空题】**` 等；页面会把它拆成题型标签。
- 选择题必须逐行写出 A/B/C/D 选项；答案给出正确选项和解析。
- 计算题给公式与代入过程；简答题给分点要点；应用题给场景与判断依据。
- `answer_md` 建议格式：`**答案：** ...` 换行 `**解析：** ...`。
- `difficulty` 取 `基础` / `进阶` / `挑战`。
- 不要只问「是什么」；题目要能检验理解、计算或迁移。

## 5. 分块与合并

- 每 12 页一块（`COURSE_CHUNK_SLIDES` 默认 12），按幻灯片顺序。
- 相邻块可能重复讲同一个知识点：保留内容更完整的一条，重要度取较高值，练习去重后保留（最多 4 道）。
- 脚本按标题归一化去重（去掉标点、空格、大小写差异），并过滤第 2 节的事务性标题。

## 6. 块 JSON 结构

每块一个文件，例如 `work/chunks/chunk-01.json`：

```json
{
  "slide_from": 1,
  "slide_to": 12,
  "summary": "本段一句话概括",
  "knowledge_points": [
    {
      "title": "中断的响应过程",
      "content_md": "**定义**：……\n\n**关键要点**\n- ……\n\n**步骤**\n1. ……\n\n**易错点**\n- ……",
      "importance": 4,
      "examples": [
        {
          "kind": "choice",
          "question_md": "**【选择题】**中断响应时，CPU 保存的断点是（ ）\nA. 当前指令地址\nB. 下一条指令地址\nC. 中断服务程序入口\nD. 栈顶地址",
          "answer_md": "**答案：** B\n**解析：** 中断返回后要执行原程序的下一条指令，因此保存的是下一条指令地址。",
          "difficulty": "基础"
        },
        {
          "kind": "short_answer",
          "question_md": "**【简答题】**简述中断响应的主要步骤。",
          "answer_md": "**答案：** ① 检查中断请求；② 关中断并保存断点与现场；③ 识别中断源、查中断向量表；④ 执行中断服务程序；⑤ 恢复现场、开中断并返回。\n**解析：** 按时间顺序答全五步即可。",
          "difficulty": "进阶"
        }
      ]
    }
  ]
}
```

`slide_from` / `slide_to` 可省略；脚本只用于排序和展示，不参与内容判断。

## 7. Markdown 子集（页面只支持这些）

- 标题 `#`–`####`、段落、`- ` 无序列表、`1. ` 有序列表
- `**粗体**`、`*斜体*`、`` `行内代码` ``、`[文字](https://...)`
- `> 引用`、`---` 分隔线、围栏代码块、简单表格
- 不支持嵌套列表、图片、原始 HTML；不要用这些写法。
